# 能量场测猫 · Energy Cat

纯前端引流钩子 Demo：**上传白墙前的手背照，AI 做「曝光↓ 饱和↑」能量显影，解析你的能量光，并为你匹配一只同频的猫。**

属于「云养虚拟宠物 + 流浪猫互动教育」主航道（方向3）的先行获客钩子。

## 玩法
1. 在**自然光、白墙前**拍一张**手背照**上传（画面尽量干净）。
2. 浏览器本地完成「曝光↓ 饱和↑」能量显影（aura 效果）。
3. 解析手部能量色 → 判定 9 色能量场（灰/黑/蓝/粉/红/绿/白/金/紫）。
4. 按能量 → 猫性格 → 品种，参数化生成你的专属同频猫（SVG），可下载分享卡。

## 运行（完全离线，无需服务器）
- 直接双击打开 `index.html` 即可使用；
- 或本地起静态服务：`python3 -m http.server 8000`，访问 http://localhost:8000 。

## 部署到 GitHub Pages
1. 新建仓库，把本目录（`energy-cat/`）内容复制到仓库根目录；
2. 推送：`git add -A && git commit -m "energy cat demo" && git push`；
3. 仓库 **Settings → Pages → Source** 选 `main` / `root` → Save；
4. 约 1 分钟后访问 `https://<用户名>.github.io/<仓库名>/`。

## 体积与性能
- 全部为文本（HTML/CSS/JS），总计约 **< 60 KB**，远低于 25 MB 限制，加载极快。
- 图片处理在浏览器本地完成（Canvas），不上传任何服务器；大图自动缩至 1000px 以保证速度。
- 零第三方依赖、无构建步骤。

## 能量色文化溯源（仅供参考，娱乐向）
能量场 / 灵光（aura）概念横跨多文化：
- **中医五色**：《内经》以「青赤黄白黑」配五脏（《素问·阴阳应象大论》）；
- **西方灵光研究**：Leadbeater《Man Visible and Invisible》(1903) 系统描述灵光颜色含义；
- **现代人体辉光**：基里安摄影（Kirlian photography）对红橙黄绿蓝紫白等彩光含义的归纳。

> ⚠️ 本测试为娱乐向，结果受光线与肤色影响，**非科学诊断**。
